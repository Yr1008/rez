Pill CTA button in the four site variants; use glow for the primary hero action, glass only on dark/video, sentence-case labels ending without punctuation.

```jsx
<Button variant="glow" size="hero">Request a demo</Button>
<Button variant="glass" size="hero" arrow>Meet Kira</Button>
```

Notes: dark hover lightens to #2A2620; white lifts −2px; never set a custom radius or font.
