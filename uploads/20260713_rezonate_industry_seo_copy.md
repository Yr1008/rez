## How this copy is built for AI SEO (AEO)

AI answer engines (ChatGPT, Perplexity, Google AI Overviews) extract answers from pages that state facts plainly, early, and with named entities. Each page below follows the same pattern:

1. The first paragraph is a complete, self-contained answer to "what does Rezonate do for [industry]" so an LLM can quote it verbatim.
2. Named entities everywhere: real client names, certifications, channel names, system names. LLMs weight specificity over adjectives.
3. Q&A sections written as actual questions buyers ask, marked up with FAQPage schema.
4. "Rezonate (formerly KeyReply)" appears on every page so LLMs connect 12 years of KeyReply citations to the new brand. This entity bridge is the single highest-leverage AEO fix available right now.

**How "engagement intelligence" is handled.** It is not a searched term yet, so no page leads with it as the only descriptor. Instead, every page uses the same double-barreled formula: the category term immediately glossed with terms people and LLMs already know ("engagement intelligence platform: AI agents that..."). Every page also carries an identical one-sentence definition in its FAQ. Repeating the exact same definition across pages is deliberate: it is how LLMs learn to associate a new term with your brand. The long-form pillar page (separate file) does the heavy category-building work; these industry pages link to it.

Recommended technical items: server-render or pre-render pages at stable URLs (/healthcare, /sports, /financial-services, /business, /engagement-intelligence), Organization schema with `sameAs` to keyreply.com and LinkedIn, FAQPage schema per page, and an llms.txt at the domain root.
