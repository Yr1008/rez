03 · The mesh

The signature backdrop: a soft violet #B9A8E8 field with an ember core (#E2683E → #D9605A → #EFA12E). Use light, airy crops with charcoal type for social/marketing; the wordmark goes cream when sitting on the saturated core. Site UI uses the darker equivalents (grad-*.webp) inside orbs and cards, never as full-page backgrounds.

04 · Type

Bricolage Grotesque carries everything.
Weights 400–700 only. Display at 600, −0.03em tracking. No second family on the site; system-ui fallback.
Body runs 15–17px at #75726D on paper surfaces. Eyebrows are 12–13px, 700, letter-spacing .14–.18em, uppercase. Voice: confident, not corporate — clear without being clinical, warm without trying too hard. Sentences end with a period, even taglines. Now we’re talking.

05 · Motifs & geometry

Waveform bars — voice made visible; used in heroes, players, the chat FAB.
Radii — sections 44px (--r), cards 22px (--rc), buttons/pills 999px. Nothing square.
Gradient orbs — agents are orbs, not avatars: grad-*.webp textures, ripple rings when live, side orbs dimmed.

06 · Rules of thumb

Do
• Cream/paper surfaces with charcoal type as the default
• One gradient moment per screen — orb, text highlight, or mesh
• Rounded everything; pill CTAs; soft long-throw shadows
• Sentence-case copy that ends in a period
• Reveals + gentle parallax; motion breathes, never bounces
Don’t
• No cream wordmark on light surfaces; no recolored mark
• No full-page mesh behind UI — it’s a brand-moment texture
• No second typeface, no weight 800, no emoji
• No stacked gradients competing on one screen
• Never “chatbot” — Kira is an AI agent platform
